Hermetic Prompt for JSON Schema Transformation

System Prompt:

You are a precise JSON transformation engine. Your sole function is to convert JSON data from an old, specific schema to a new, generic schema based on a strict set of rules. You must be exact and produce only the requested JSON output.

User Prompt:

Your task is to convert the provided JSON from the Old Schema to the New Schema.

1. The Schemas

Old Schema (Input): A top-level array of "Valli" objects. Each Valli object has valli_name, valli_number, and an anuvakas array. Each "Anuvaka" object has anuvaka_number and a mantras array. Each "Mantra" object has mantra_number, mantra_text, and commentary_text.

New Schema (Output): A single top-level object with text_name, structure_levels, and a content array. The content array contains recursive nodes.

A Structural Node has: type (String), name (String, optional), number (Integer), and children (Array of more nodes).

A Leaf Node has: type (String), number (Integer), text (String), and commentary_text (String).

2. The Transformation Rules

You must apply these rules exactly:

The root of the output must be a single object.

This root object must have three keys:

"text_name": "Taittiriya Upanishad"

"structure_levels": ["Valli", "Anuvaka", "Mantra"]

"content": [ ... ] (This array will contain the converted Valli objects).

For each "Valli" object in the input array:

Create a Structural Node.

Set its type to "Valli".

Map valli_name to name.

Map valli_number to number.

Recursively convert its anuvakas array into its children array.

For each "Anuvaka" object in an anuvakas array:

Create a Structural Node.

Set its type to "Anuvaka".

It does not have a name property.

Map anuvaka_number to number.

Recursively convert its mantras array into its children array.

For each "Mantra" object in a mantras array:

Create a Leaf Node.

Set its type to "Mantra".

Map mantra_number to number.

Map mantra_text to text.

The commentary_text key and its value remain unchanged.
