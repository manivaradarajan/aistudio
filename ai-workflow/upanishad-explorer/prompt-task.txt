Accuracy and strict adherence to the schema are paramount.

// The main object for the entire file
interface RootObject {
  text_name: string;
  structure_levels: string[];
  content: (StructuralNode | LeafNode)[];
}

// A node that contains other nodes (e.g., a Chapter, a Valli, a Khanda)
interface StructuralNode {
  type: string;
  name: string;       // The display name of the section (e.g., "प्रथमः खण्डः"). THIS IS A REQUIRED FIELD.
  number: number;
  children: (StructuralNode | LeafNode)[];
}

// The final content node that holds the text (e.g., a Mantra, a Sutra)
interface LeafNode {
  type: string;
  number: number;
  text: string;
  commentary_text?: string; // Commentary can be optional
}
Part 3: The Task and Instructions

I will provide you with the raw text of an entire scripture. Your job is to perform the following steps meticulously:

Discern the Structure: First, analyze the entire text to determine its hierarchy. Define the structure_levels array based on your analysis.

Example for Aitereya Upanishad: ["Khanda", "Mantra"]

Construct the JSON (Adhering to the Schema):

For Structural Nodes (like Khanda or Valli):

The type property MUST be the corresponding name from structure_levels.

The name property MUST be extracted from the text's heading (e.g., प्रथमः खण्डः). This is a mandatory field.

The number property must be correctly identified.

It MUST contain a children array.

For Leaf Nodes (like Mantra):

The type property MUST be the last name from structure_levels.

It contains the text and commentary_text properties.

Associate Content: Intelligently segment the commentary and assign the relevant parts to the specific LeafNode (Mantra, Sutra, etc.) it explains.

Enhance with Markdown:

Bolding: Within commentary_text, find direct quotes or key terms from the text and make them bold using double asterisks (**word**).

Linking: Find references to other texts in parentheses, like (बृ.उ. 6-4-22), and convert them into Markdown links with a structured path, like [बृ.उ. 6-4-22](/reference/brihadaranyaka-upanishad/6/4/22).

Subheadings: Preserve subheadings found within the commentary by converting them to Markdown headings (e.g., #### अवतारिका).

Handle Special Cases: Introductory sections like a शान्तिमन्त्रः (Shantimantra) should be treated as the first LeafNode of the relevant section, often with number: 0.

Final Validation Check: Before outputting the final JSON, perform a self-correction check:

Is the entire output a single, valid JSON object?

Does every StructuralNode have a type, name, number, and children property?

Does the text_name match the scripture's name?

Is the structure_levels array accurate for the text's hierarchy?

By aligning your prompt with your formal schema, you create a robust and reliable system for data generation.
