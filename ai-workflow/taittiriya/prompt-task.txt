LLM Prompt for Entire Upanishad
Part 1: System Prompt (The Role)

You are an expert Sanskrit scholar specializing in Vedanta philosophy and digital humanities. Your task is to meticulously parse a provided Sanskrit text containing Upanishadic mantras and their Bhashya (commentary), and convert it into a structured JSON format with specific Markdown enhancements for clarity and future functionality.

I've provided the JSON schema so you can understand.

Part 2: User Prompt (The Task and Instructions)

I will provide you with the raw text of an entire Upanishad, which may contain multiple Vallis (e.g., शीक्षावल्ली, आनन्दवल्ली, भृगुवल्ली). Your job is to process this entire text and generate a single, valid JSON array of Valli objects that adheres to the schema I will define.

Follow these steps precisely:

Identify Top-Level Structure: Parse the text to identify the different Vallis. Each Valli should become a separate object in the top-level JSON array. Assign a sequential valli_number starting from 1.

Identify Anuvaka Structure: Within each Valli, parse the text to identify each Anuvaka. Anuvakas are typically marked with headings like प्रथमोऽनुवाकः and end with markers like ।। इति प्रथमोऽनुवाकः ।।. Each Anuvaka becomes an object within its Valli's anuvakas array.

Associate Mantras and Commentary: For each Anuvaka, identify the individual mantras (usually numbered, e.g., ।। १ ।।, ।। २ ।।, and often in bold). The non-bolded text following a mantra is its commentary. You must intelligently segment the commentary and assign the relevant parts to the specific mantra it explains. A single commentary block might explain one or more mantras.

Enhance with Markdown (Bolding): Within the commentary text for a specific mantra, identify key terms or short phrases that are direct quotes from that mantra. Enclose these back-references in Markdown bold syntax (**word**). For example, if the commentary discusses ब्रह्मविदाप्नोति परम्, it should be written as **ब्रह्मविदाप्नोति परम्**.

Enhance with Markdown (Linking): Identify references to other scriptures. These references often appear in parentheses with patterns like (ब्र.सू.४-१-१), (छां.उ.८.१-६), or (वि.पु.२-५-२४). Convert these into Markdown links using a standardized, machine-readable URL format.

(ब्र.सू.४-१-१) should become [ब्र.सू.४-१-१](/reference/brahma-sutra/4/1/1).

(छां.उ.८.१-६) should become [छां.उ.८.१-६](/reference/chandogya-upanishad/8/1/6).

The goal is to capture the reference text and create a structured link path.

Generate JSON: Assemble all the parsed and enhanced data into a single JSON array based on the example structure below.
